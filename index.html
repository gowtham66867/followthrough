FIVE MINUTES / TWO CLEAR MODES

Start here, judges.

1. Browser walkthrough: Review the fictional answers and sourced deadline, approve, then add the client amendment. Inspect the impact map and reopened approval. No live AI runs on this website.

2. Working app: Download the v0.5 test build. The guided workflow is offline; explicitly selecting Analyze with NVIDIA calls Nebius Token Factory using configured credentials. Free hosted live judge access is still pending a suitable server. No invitation or API key is published here.

3. Inspect the evidence: On 16 author-labelled synthetic development cases, the retained model prompt passed 12 complete cases. The application's deadline precision guard raised that to 14/16 by keeping invented precision unresolved. Requirement recall was 18/20 and labelled precision 18/19. Two extraction failures remain: mandatory amendment classification and an omitted optional attachment.

All 19 model requirement quotes could be located in their sources; this does not establish semantic correctness. These are small development observations, not held-out accuracy or customer ROI. A rejected prompt experiment is preserved in the repository.
