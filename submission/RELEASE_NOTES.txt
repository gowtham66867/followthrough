FollowThrough v0.2.0 — local proposal-readiness test build

For judges: download followthrough-v0.2.0.zip, extract it, create a Python 3.11+ virtual environment, install requirements.txt, and run run.py. Open http://127.0.0.1:8787 and select Load guided demo. The frontend is already built in the ZIP.

No login or API key is needed for the explicitly labelled fictional guided walkthrough. Live NVIDIA analysis requires your own Nebius Token Factory key and config.yaml; full instructions are in README.md. No developer key or private user data is distributed.

Features: sourced requirements, PDF/DOCX/text import, approved company evidence, missing-input tasks, amendment impact review, approval invalidation, DOCX/attachment export, separate submission and receipt evidence.

Validation: 9 standalone tests passed; 11 including development-only starter coverage. Six small fictional live NVIDIA smoke examples passed strict schema, citation and expected-keyword checks. No production accuracy or customer impact is claimed.

The 2:30 narrated walkthrough is attached as followthrough-demo.mp4. It uses actual application captures and explicitly fictional client/company information.

Boundaries: single-owner local application, no OCR or public multi-tenant hosting. Evidence excerpts require human relevance review. Gmail OAuth is optional and unverified. External submission remains manual. Do not expose this app publicly through a tunnel.
