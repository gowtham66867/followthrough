FollowThrough v0.4.0 — proposal impact map and actionable final review

Download followthrough-v0.4.0.zip, extract, create a Python 3.11+ virtual environment, install requirements.txt and run run.py. Open http://127.0.0.1:8787. The frontend is already built.

New:
- Before you submit: one action queue for source review, missing or unreviewed answers, unsupported claims, missing attachments, deadlines and unresolved conflict decisions. Advisory owner assignments and exceptions are separate from blockers.
- Impact map: trace source → requirement → selected evidence → answer → attachment/owner → package approval. Compare original and amended wording; filter changed obligations; open the exact source, evidence record, answer or owner form.
- One backend readiness contract drives the screen, approval, export and user-reported submission. Expired evidence blocks an earlier approval even if its hash has not changed. Read-only projections do not alter revisions.
- Missing-attachment actions preselect the deliverable; owner actions open its assignment form. Unanalyzed amendments explicitly show incomplete mapping.

Retained from v0.3: Qwen semantic evidence search followed by NVIDIA chat relevance assessment, human-reviewed NVIDIA vision transcription, and optional source-cited NVIDIA reasoning for conflicts. The dedicated Qwen reranker was unavailable on the tested account. Live features require your own Nebius key and YAML configuration. The explicitly fictional guided walkthrough works without credentials; no private developer key is distributed.

Validation: 13 standalone automated tests plus two development-only starter tests. Added contracts cover amendment/source/evidence/owner/approval links, restart persistence, expired evidence and consistent approval/export/submission gates. The browser walkthrough covered approval, a late amendment, changed wording and attachment targeting at desktop and narrow widths. Earlier v0.3 live smoke results are retained; no new inference path was introduced in v0.4.

Original public 2:30 demo (v0.2 core workflow): https://www.youtube.com/watch?v=TGrqRwF3qm0
The video does not show v0.3/v0.4 additions. See submission/12 through 17 screenshots for new features.

Single-owner local application, not public hosting or a multi-tenant service. Links reflect stored associations and model-proposed requirement keys; a person verifies authority, relevance and completeness. No agency pilots, measured savings, production accuracy, legal guarantee or autonomous bid submission are claimed. Optional Gmail OAuth remains unverified.
